config.json Reference

The config.json file is the heart of your mkapk project. It defines all build settings, directory mappings, dependencies, and native toolchain targets.

​

Basic Structure

{
"NAME": "MyApplication",
"BIN_DIR": "bin",
"SRC_DIR": "src",
"RES_DIR": "res",
"ASSETS_DIR": "assets",
"MANIFEST": "AndroidManifest.xml",
"SDK_ROOT": "/android-sdk/Sdk",
"TARGET_SDK": "36",
"MIN_SDK": "21",
"JAVA_VERSION": "17",
"COMPOSE_PLUGIN": "",
"PROGUARD_RULES": "proguard-rules.pro",
"KEYSTORE": "/.android/debug.keystore",
"KEYSTORE_ALIAS": "androiddebugkey",
"NDK_BIN": "",
"SYSTEM_SHARED_LIBS": [],
"DEPENDENCIES": [],
"NATIVE_TARGETS": []
}
​

Field Reference

​
Field Type Required Description
NAME String No Application name (default: "MyApp"; used for output APK filename).
BIN_DIR String (path) No Build output directory (default: "bin"). Final APKs are placed in bin/debug or bin/release.
SRC_DIR String (path) No Source directory containing Java, Kotlin, and native code (default: "src").
RES_DIR String (path) No Android resources directory (default: "res").
ASSETS_DIR String (path) No App assets directory packaged directly into the root APK (default: "assets").
MANIFEST String (path) No Path to primary AndroidManifest.xml (default: "AndroidManifest.xml").
SDK_ROOT String (path) No Android SDK root directory (default: "/android-sdk/Sdk"). Supports expansion.
TARGET_SDK String (number) Yes Target Android API level (default: "36"). Triggers automatic platform download if missing.
MIN_SDK String (number) Yes Minimum Android API level used for D8/R8 desugaring and manifest merging (default: "21").
JAVA_VERSION String (number) No Java source and release byte compatibility level passed to javac (default: "17").
COMPOSE_PLUGIN String (path) No Path to Jetpack Compose Kotlin compiler plugin JAR.
PROGUARD_RULES String (path) No ProGuard / R8 rules file applied during release builds (default: "proguard-rules.pro").
KEYSTORE String (path) Yes (release) Release keystore file path. Automatically resolves within the current workspace and the keystores/ directory.
KEYSTORE_ALIAS String Yes (release) Release signing certificate alias.
NDK_BIN String (path) No Custom NDK toolchain bin directory. If omitted, uses Clang/LLVM from Termux ($PREFIX/bin).
SYSTEM_SHARED_LIBS Array[String] No System or prebuilt shared libraries to bundle in APK lib/ (e.g., "c++_shared", "log").
DEPENDENCIES Array[String] Yes (if the project has dependencies) Remote Maven coordinates for AAR and JAR dependencies resolved transitively via Eclipse Aether.
NATIVE_TARGETS Array[Object] No Native C/C++ compilation targets compiled into standalone shared libraries (see below).
​

Dependencies & Local Libraries

​

Remote Dependencies (DEPENDENCIES)

mkapk features a native dependency resolver powered by Maven Artifact Resolver (formely Aether) within the persistent background daemon.

​
"DEPENDENCIES": [
"androidx.core:core-ktx:1.13.0",
"androidx.appcompat:appcompat:1.7.0",
"com.google.code.gson:gson:2.11.0"
]
​

Local JAR Libraries (libs/)

Any local .jar files dropped into the root libs/ directory are automatically detected and appended to the classpath for javac, kotlinc, d8, and r8 without requiring manual entries in config.json.

​

Native Targets Configuration

Define custom native compilation targets for C and C++ source code:

​
"NATIVE_TARGETS": [
{
"NAME": "native_core",
"SOURCES": [
"src/C++/native_bridge.cpp",
"src/C/core_logic.c"
],
"EXTRA_FLAGS": [
"-fexceptions",
"-frtti",
"-std=c++17"
]
}
]
​

Native Target Fields

Field Type Description
NAME String Target library name without prefix or extension (produces lib.so).
SOURCES Array[String] List of source files (.c, .cpp, .cc, .s) to compile.
EXTRA_FLAGS Array[String] Additional compiler and linker flags passed to Clang/Clang++ (e.g., -std=c++17, -O3).
​

System Shared Libraries

Specify shared libraries to pull into the final APK archive:

​
"SYSTEM_SHARED_LIBS": [
"c++_shared",
"log",
"android"
]
​

ProGuard / R8 Configuration

Create a proguard-rules.pro file for whole-program optimization and code obfuscation during release builds (mkapk build -release):

​
# Keep all public classes and methods
-keep public class * {
public *;
}
​Keep JNI native bridge functions
​-keepclasseswithmembernames class * {
native ;
}
​Keep enumeration values
​-keepclassmembers enum * {
public static [] values();
public static  valueOf(java.lang.String);
}
​Keep Android entry points
​-keep public class * extends android.app.Activity
-keep public class * extends android.app.Service
-keep public class * extends android.content.BroadcastReceiver
​

Example Configurations

​

Standard Kotlin / Java App with Dependencies

{
"NAME": "ModernApp",
"BIN_DIR": "bin",
"SRC_DIR": "src",
"RES_DIR": "res",
"MANIFEST": "AndroidManifest.xml",
"SDK_ROOT": "~/android-sdk/Sdk",
"TARGET_SDK": "36",
"MIN_SDK": "21",
"JAVA_VERSION": "17",
"DEPENDENCIES": [
"androidx.appcompat:appcompat:1.7.0",
"androidx.core:core-ktx:1.13.0"
]
}
​

App with Native C/C++ Code

{
"NAME": "NativeApp",
"BIN_DIR": "bin",
"SRC_DIR": "src",
"RES_DIR": "res",
"MANIFEST": "AndroidManifest.xml",
"SDK_ROOT": "~/android-sdk/Sdk",
"TARGET_SDK": "36",
"MIN_SDK": "21",
"JAVA_VERSION": "17",
"SYSTEM_SHARED_LIBS": ["c++_shared", "log"],
"NATIVE_TARGETS": [
{
"NAME": "native_core",
"SOURCES": [
"src/C++/native_bridge.cpp",
"src/C/core_logic.c"
],
"EXTRA_FLAGS": ["-std=c++17"]
}
]
}
