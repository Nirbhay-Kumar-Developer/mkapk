Installation Guide

Get mkapk up and running on your Termux environment

  • Home
  • Installation

The easiest way to install mkapk is using our automated installation script. We recommend compiling from source to ensure native compatibility with your architecture.

Method 1: Compile from Source (Recommended)

Run the installer with the --compile flag to automatically install all build-time toolchain dependencies (maven, make, git, python), clone the repository, compile from source, and install the package:

bash <(curl -fsSL https://raw.githubusercontent.com/Nirbhay-Kumar-Developer/mkapk/main/install.sh) --compile

Method 2: Install Pre-built Package

If you prefer to install using the pre-compiled aarch64 Debian package directly:

bash <(curl -fsSL https://raw.githubusercontent.com/Nirbhay-Kumar-Developer/mkapk/main/install.sh)

Verify Installation

Check if mkapk was installed correctly and verify its version:

mkapk --version

You can also view all available commands:

mkapk --help
Installation Complete! You can now proceed to the Quick Start Guide.

Troubleshooting Installation

Issue: "mkapk: command not found"

The binary may not be in your PATH. Try verifying with:

which mkapk

Issue: "Permission denied"

Ensure the binary has execute permissions:

chmod +x $PREFIX/bin/mkapk
